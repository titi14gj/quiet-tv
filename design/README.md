# 浏览器样稿与图标源

此目录是开发过程中的设计参考，不是 5.2 原生 APK 的实时镜像。

从仓库根目录启动：

```sh
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/design/ 。样稿包括壁纸、卡片、玻璃控件和图标目录；当前原生应用新增的第二排提示与独立应用页以实机截图和 Java 源码为准。

`catalog.js` 是其他入口的可编辑图稿；运行 `node design/export-icons.cjs` 可重新导出透明前景，依赖 sharp。APK 构建不需要启动预览服务器，也不需要重新导出图标。

# 电视机内初始化向导（5.4-rc1 测试版）

入口：静境 TV 右上角设置 → **电视初始化与精简**。首页、壁纸和图标设计不变。

## 安装和授权是两件事

APK 可以拷到 U 盘，再用电视文件管理器安装；若电视支持其他安装方式也可以使用。安装 APK 本身不要求电脑 ADB，电视仍可能要求启用“未知来源”或确认安装。

读取型号、Android 版本、固件版本和预装包清单，不需要 ADB 授权。执行系统包管理，需要 **ADB shell 权限**。本版内置传统 ADB 客户端，仅连接电视自身的 `127.0.0.1`，默认端口 5555；不连接其他设备、不上传清单。

操作流程：

1. 安装并打开静境 TV，确认桌面、设置和信号源可用。
2. 进入向导，查看设备信息和预装应用清单。
3. 在电视开发者选项开启网络 ADB。仅开启“USB 调试”不一定开放 TCP 端口；不提供网络开关的固件，可能需要先通过电脑/USB 执行 `adb tcpip 5555`。
4. 回到向导，选择“连接本机 ADB”。首次连接若系统弹出 RSA 授权框，用遥控器确认；可按需要允许记住此授权。向导里的普通确认框不能授予系统权限。
5. 匹配已验证固件后，手动勾选需要处理的广告组件或原厂桌面，再确认执行。默认全部不勾选。
6. 查看每项读回的状态。按 Home 测试，正常重启后再次连接检测，确认默认桌面与组件状态是否保持。向导不自动重启。

若网络 ADB 未开启、固件拒绝本机连接、没有可操作的系统授权框，机内流程无法继续；仍需电脑辅助。Android 11 及以上的配对码/TLS 无线调试不在本版支持范围内。旧式网络 ADB 也可能向局域网开放，开关与授权由电视固件控制。

## 自动操作的范围

此候选版只对以下**完全匹配**的原有实机配置提供修改规则：

- 微鲸 65D2UT，API 21，显示版本 `HELIOSR-02.08.03 release-keys`；
- 指纹 `Helios/helios/helios:5.0.1/HELIOSR-02.08.03/1849508:user/release-keys`。

只允许处理 `com.helios.launcher`、`com.helios.ad.service`、`cn.whaley.adsys` 三个包。其他设备可检测，不会按名字批量精简。应用还会核对 ADB 返回的 UID 与固件指纹。

该固件使用先前实机验证过的 `pm hide --user 0`，令包对当前用户不可用，**不是删除 APK，也不是更改 enabled 字段**。每项都重新读取用户 0 的包状态；命令返回成功而状态没变，会报告失败。进程退出与重启持久性需另行复查。这里只覆盖独立广告组件，不能保证去掉开机画面、播放器和第三方应用内部广告。

桌面接管先确认静境 TV 已安装并能登记为 HOME 首选，再处理原桌面，最后核对 HOME 解析结果。解析失败会尝试恢复本次处理的原厂桌面；恢复也无法确认时明确报告，不显示成功。首选项和最终开机行为仍需实机验证。

## 恢复与授权信息

“恢复本向导的修改”只针对向导执行前可用、由向导设为 hidden 的包。原先通过电脑或其他工具设为不可用的包不会加入记录，也不会自动取消限制。恢复记录在修改前同步保存；结果未知时保留记录供重试。

记录保存在应用数据中。恢复前不要清除静境 TV 数据或卸载应用，否则记录会丢失；仍可使用仓库里的电脑恢复脚本。恢复只保证检查包可用状态，不能还原此前所有 HOME 首选记录。

每次安装生成独立 RSA-2048 ADB 身份，密钥只保存在应用私有目录；不是 APK 发布签名密钥。此版关闭应用备份，新增 INTERNET 权限用于本机 TCP 连接，无云端服务。电视系统中已记住的 ADB 授权可从开发者选项撤销。退出向导会关闭当前连接。

已完成：构建、APK 签名检查、API 19 静态检查、API 33 模拟器方向键进入向导/预装清单/本机 ADB 连接与身份校验/未适配固件禁止修改，以及独立 JVM 测试（协议校验、RSA 编码、授权握手、退出码、设备规则、已有状态保护、桌面解析失败恢复）。

# 电视机内初始化向导（5.4 候选版）

入口：静境 TV 右上角设置 → **电视初始化与精简**。首页、壁纸和图标设计不变。

## 安装和授权是两件事

APK 可以拷到 U 盘，再用电视文件管理器安装；若电视支持其他安装方式也可以使用。安装 APK 本身不要求电脑 ADB，电视仍可能要求启用“未知来源”或确认安装。

读取型号、Android 版本、固件版本和预装包清单，不需要 ADB 授权。执行系统包管理，需要 **ADB shell 权限**。本版内置传统 ADB 客户端，仅连接电视自身的 `127.0.0.1`，默认端口 5555；不连接其他设备、不上传清单。

操作流程：

1. 安装并打开静境 TV，确认桌面、设置和信号源可用。
2. 进入向导，查看设备信息和预装应用清单。
3. 在电视开发者选项开启网络 ADB。仅开启“USB 调试”不一定开放 TCP 端口；不提供网络开关的固件，可能需要先通过电脑/USB 执行 `adb tcpip 5555`。
4. 回到向导，选择“连接本机 ADB”。首次连接若系统弹出 RSA 授权框，用遥控器确认；可按需要允许记住此授权。向导里的普通确认框不能授予系统权限。
5. 匹配已验证固件后，手动勾选需要处理的广告组件或原厂桌面，再确认执行。默认全部不勾选。
6. 查看每项读回的状态。按 Home 测试，正常重启后再次连接检测，确认默认桌面与组件状态是否保持。向导不自动重启。

若网络 ADB 未开启、固件拒绝本机连接、没有可操作的系统授权框，机内流程无法继续；仍需电脑辅助。Android 11 及以上的配对码/TLS 无线调试不在本版支持范围内。旧式网络 ADB 也可能向局域网开放，开关与授权由电视固件控制。

## 自动操作的范围

5.4-rc1 仅对以下**完全匹配**的原有实机配置提供修改规则（rc2 扩展范围见后文）：

- 微鲸 65D2UT，API 21，显示版本 `HELIOSR-02.08.03 release-keys`；
- 指纹 `Helios/helios/helios:5.0.1/HELIOSR-02.08.03/1849508:user/release-keys`。

只允许处理 `com.helios.launcher`、`com.helios.ad.service`、`cn.whaley.adsys` 三个包。其他设备可检测，不会按名字批量精简。应用还会核对 ADB 返回的 UID 与固件指纹。

该固件使用先前实机验证过的 `pm hide --user 0`，令包对当前用户不可用，**不是删除 APK，也不是更改 enabled 字段**。每项都重新读取用户 0 的包状态；命令返回成功而状态没变，会报告失败。进程退出与重启持久性需另行复查。这里只覆盖独立广告组件，不能保证去掉开机画面、播放器和第三方应用内部广告。

桌面接管先确认静境 TV 已安装并能登记为 HOME 首选，再处理原桌面，最后核对 HOME 解析结果。解析失败会尝试恢复本次处理的原厂桌面；恢复也无法确认时明确报告，不显示成功。首选项和最终开机行为仍需实机验证。

## 恢复与授权信息

“恢复本向导的修改”只针对向导执行前可用、由向导设为 hidden 的包。原先通过电脑或其他工具设为不可用的包不会加入记录，也不会自动取消限制。恢复记录在修改前同步保存；结果未知时保留记录供重试。

记录保存在应用数据中。恢复前不要清除静境 TV 数据或卸载应用，否则记录会丢失；仍可使用仓库里的电脑恢复脚本。恢复只保证检查包可用状态，不能还原此前所有 HOME 首选记录。

每次安装生成独立 RSA-2048 ADB 身份，密钥只保存在应用私有目录；不是 APK 发布签名密钥。此版关闭应用备份，新增 INTERNET 权限用于本机 TCP 连接，无云端服务。电视系统中已记住的 ADB 授权可从开发者选项撤销。退出向导会关闭当前连接。

## 5.4-rc2：内置参考目录与报告导出

流程调整为：安装 → 自动匹配固件 → 连接并授权 → 执行已匹配规则。只有没有可执行规则或执行失败时，才需要导出报告、分析适配并更新 APK。

### 当前覆盖范围

- **微鲸 65D2UT 原有固件**：保留前述精简及桌面接管规则；新机内执行流程仍待真机全流程验证。
- **TCL Smart TV Pro / G08 / API 31**：只在指纹完整匹配 `TCL/G08_4K_GB/G08:12/STT2.221228.001/AS34:user/release-keys` 时，提供三项社区参考精简选项：`com.tcl.dashboard`、`com.tcl.messagebox`、`com.tcl.logkit`。源于上游实测清单，本项目未实机验证；不搬入原清单里的浏览器、语音、投屏、屏保、更新、设置向导和桌面相关操作。
- **其他电视**：保留系统包，可使用系统默认桌面设置；API 24 及以上在本机 ADB 授权后，还可尝试标准 HOME 登记，读回 HOME 解析后才确认结果。厂商拒绝或重启后复位时，需要继续适配。这不是绕过厂商锁定的通用接管方案。

“查看上游社区机型参考”内置 243 条记录，来自固定提交 `5e9e4f119e405eb8bcc18296f2567c9d6a7c4217` 的 `examples/README.md`。**243 条参考不等于 243 款可自动修改或接管**：社区案例包含成功、仅精简可用、HOME 锁定、安装受限等不同情况。当前只有上面列出的精简规则能够执行，不会根据品牌或型号近似匹配放开系统操作。后续可逐步转成更多执行规则，桌面 UI 无需随之改变。

### 导出报告

点击“导出适配报告”：未连接 ADB 时生成基础报告；已连接并重新核对身份后，增加授权诊断。报告包括设备/固件、包名及版本、系统包标志和启用状态、HOME 候选/解析；授权报告还包含停用包清单、ADB UID、匹配规则内的包状态。读取失败也会记录，不能把缺失数据当作正常。

系统有文件选择器时，可选择 U 盘或其他保存位置。没有文件选择器时尝试系统分享；再不可用则保存到本应用外部文件目录并显示路径，可尝试用电视文件管理器复制。部分电视缺少这些组件，或限制访问应用目录，不能保证每台电视都能直接拷出；报告生成和对外保存分别显示结果。

报告不自动上传，不包含硬件序列号、账号、SSID 或 Wi-Fi 密码。保存后由用户自行发给维护者。报告只能帮助分析，不代替陌生机型的恢复、HOME 和重启实测。

### 规则与恢复

社区目录只用于查询，不当作脚本执行；可执行清单由代码单独声明。TCL 规则采用 `pm disable-user --user 0`，逐项确认 enabled=3；执行前同步记录原 enabled=0 或 1，恢复时分别回到 default-state 或 enable。原先已停用、hidden 或未安装的包不改动、不加入恢复记录。

标准 HOME 登记保留原厂包，可从系统默认桌面设置改回。它不保证所有厂商允许，也不替用户处理 Google TV 设置向导、Wi-Fi、投屏依赖等机型差异。

开发者可用 `scripts/import-upstream-catalog.py --commit <完整提交 SHA>` 更新参考目录。此脚本不会增加可执行规则；执行规则需要单独整理、检查和验证。本版没有在线规则下载或静默更新 APK。
